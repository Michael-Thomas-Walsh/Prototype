# Viewer interaction and legibility update (v0.6)

- Click a model element to select it; click it again, or click empty canvas space, to clear selection.
- Selected elements are highlighted with warm, high-contrast shading and geometry-edge overlays.
- When Ghost context is enabled, nonselected mesh objects fade to 19% while selected mesh geometry remains opaque. Selected AABB guides are subdued.
- Different model categories are assigned distinct, readable **illustrative** materials; these are NOT actual Revit material appearances. PBR lighting and flat shading improve form reading.
- The sync notification has minimise (+/−) and close (×) controls. The Inspector has minimise and close/clear controls.
- This is a visualisation update; it does not change the underlying geometry extractor, clash calculation, or real Speckle version check.

## Installation

Back up `D:\Fusion_Prototype\fusion_bim_platform`, particularly any SQLite database and generated GLBs in `frontend/public/data/meshes`. Extract the ZIP into `D:\Fusion_Prototype` and allow file replacements; do not delete the existing folder. Restart frontend (`npm run dev`) and refresh the page. Restart backend only if it is not running. Existing meshes are reused—no new export necessary.

## Limitations

The GLB data generated by the current exporter does not preserve Autodesk material definitions or material textures. The colours in this version use category heuristics. Selected edges are deliberately restricted to selected elements for performance. To replicate Revit materials faithfully, the Speckle/GLB exporter must carry material definitions and per-face grouping.

The frontend dependency install could not be completed in the packaging environment, so live browser rendering must be tested locally.
